basic jkc syntax rule book (MVP VERSION)

types: int (64-bit int) and bools

variable declaration: let [varname]: type = [value]

if/else: if(expr) then { code }
            else if(expr) then { code }
            else { code }

while: while(expr) then { block }

(NOTE: for if/else and while blocks, we must use braces)

return: the send key word

binary arithmetic: Supports +, -, *, / for now

functions and function calls: fn [funcname](var: type, ...) -> send type { code }
                            function calls work normally
                            send type must be either int or bool for now

logical operators: keywords are OR, AND, NOT, instead of ||, &&, !
                    in a way, this is kind of like a mix of python and C 

comparisons: 
                is: ==
                is_lte: <=
                is_lt <
                is_gte: >=
                is_gt: >

precedence rules: 
1. Parentheses and function calls
2. Unary operations
3. Mult and Division
4. Addition and Subtraction
5. Comparison Operations (is, is_lte, is_gte . . .)
6. AND
7. OR



JKC GRAMMAR (mvp) (same idea as taught in 2fa3):

Program      → Function*

Function     → "fn" IDENT "(" Parameters? ")" "->" Type Block
Parameters   → Parameter ("," Parameter)*
Parameter    → IDENT ":" Type

Type         → "int" | "bool"

Block        → "{" Statement* "}"

Statement    → LetStmt
             | AssignStmt
             | IfStmt
             | WhileStmt
             | SendStmt
             | ExprStmt
             | Block

LetStmt      → "let" IDENT ":" Type "=" Expr ";"
AssignStmt   → IDENT "=" Expr ";"

IfStmt       → "if" "(" Expr ")" "then" Block
               ("else" "if" "(" Expr ")" "then" Block)*
               ("else" Block)?

WhileStmt    → "while" "(" Expr ")" "then" Block

SendStmt     → "send" Expr ";"
ExprStmt     → Expr ";"



examples for jkc language syntax


1) simple factorial function using recursion
fn fact(n: int) -> int {
    if (n is_lte 1) { then send 1; }
    else{
        send n*fact(n-1);
    }
}

2) standard while loop, start at 4, and increment 10 times to give 14
fn main() -> int {
    let x: int = 4;
    let i: int = 1;
    while(i is_lte 10) then {
        x = x + 1;
        i = i + 1;
    }
    send x;
}

3) simple calculator using the factorial function
fn main() -> int {
    let int x = 5;
    let int y = 3;
    let int z = fact(x*y);
    let bool ok = false;

    if(z is_gt (x+y)) then {
        ok = true;
    }
    else if(z is (x+y)) then {
        ok = true;
    }
    else { ok = false; }

    if(ok is true) { then send 1; }
    else { send 0; }
}


4) playing with logic
fn main() -> bool {
    let x: int = 1;
    let y: int = 2;

    if(NOT(x is y) AND x is_gte 1) then {
        send NOT(x is y); //returns 0 for false
    }
    else {
        send x is y; //returns 1 for true
    }
}
